<a id="capabilities"></a>
## できること

Cernere のアカウントで VANTAN GLab にログインし、GLAB の各機能を開くために必要なプロフィールを登録できます。

<a id="before-starting"></a>
## 始める前に

案内されたメールアドレスとパスワード、または登録済みのパスキーを用意します。画面構成によっては「パスキーでログイン」だけが表示されます。

新しいアカウントを作る場合は、ログイン画面に「新規登録」が表示されていることを確認してください。Cernere での本人確認は、GLAB の部員資格を保証するものではありません。

<a id="sign-in-and-register"></a>
## 操作する

1. VANTAN GLab のログイン画面を開きます。
2. メールアドレスとパスワードを入力して「ログイン」を押します。パスキーを使う場合は「パスキーでログイン」を押し、端末の案内に従います。
3. 「GLAB 初回登録」が表示されたら、「名前」「役職」「学科」をすべて入力します。
4. 「登録して GLAB を開く」を押します。入力した情報は Cernere に保存されます。

<a id="confirm-success"></a>
## 成功を確かめる

「🏠 ダッシュボード」が開き、「プロフィール」に自分の名前、学科、役職が表示されれば登録完了です。ヘッダーにも自分の名前または利用者IDが表示されます。

<a id="troubleshooting"></a>
## 困ったとき

- 「名前・役職・学科をすべて入力してください。」と表示されたら、空欄を埋めてもう一度登録します。
- 「Cernere への登録に失敗しました。時間をおいて再試行してください。」と表示されたら、少し待ってからやり直します。
- 「Cernere のプロフィールを確認できません」と表示されたら、接続が戻った後に画面を再読み込みします。
- セッション切れの案内が出たら、ログイン画面からやり直します。
