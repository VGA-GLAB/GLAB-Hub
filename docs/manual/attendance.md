<a id="capabilities"></a>
## できること

進行中のイベントがあるとき、会場でパスキーを使って自分の出席を記録できます。「今日の出席簿」で参加者の到着状況を、「直近30日の出席履歴」で自分の記録を確認できます。

<a id="before-starting"></a>
## 始める前に

次の条件を確認してください。

- GLAB へのログインと初回登録が済んでいる。
- 「イベント出席」に進行中のイベント名が表示されている。
- 端末が会場 Wi-Fi に接続され、会場の出席受付に接続できる。
- 端末でパスキーを利用できる。

<a id="check-in"></a>
## 操作する

1. 「✅ 出席」タブを開きます。
2. 「イベント出席」に表示されたイベント名と開催時間を確認します。
3. 「出席」を押します。
4. 端末にパスキーの確認が表示されたら、画面の案内に従って本人確認を完了します。

<a id="confirm-success"></a>
## 成功を確かめる

「出席を記録しました。」と表示されれば完了です。「今日の出席簿」に自分の名前・時刻・確認方法が追加され、「直近30日の出席履歴」にも記録が表示されます。

「本日の出席は既に記録されています。」と表示された場合も、その日の同じ施設での出席は記録済みです。

<a id="troubleshooting"></a>
## 困ったとき

- 「進行中のイベントはありません」と表示されたら、イベント開始後に「更新」を押します。
- 「会場Wi-Fi内のOsに接続できないため、現在は出席できません。」と表示されたら、会場 Wi-Fi への接続を確認して「更新」を押します。
- パスキー確認を完了しても失敗する場合は、もう一度やり直します。出席証明には短い有効時間があります。
- 自分で記録できない場合は、運営者に相談してください。管理者画面には「手動で記録」があります。
