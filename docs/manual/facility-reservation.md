<a id="capabilities"></a>
## できること

GLAB の「🏫 施設」タブから利用できる施設を確認し、制作や活動に使う時間を予約できます。作成した予約は「自分の予約」で確認し、不要になった場合はキャンセルできます。

<a id="before-starting"></a>
## 始める前に

ログインと初回登録を済ませ、利用したい施設、開始日時、終了日時を決めてください。「Aedilis (施設予約) に未接続」と表示されている間は、施設の確認や予約はできません。

<a id="create-reservation"></a>
## 操作する

1. 「🏫 施設」タブを開きます。
2. 「施設一覧」で利用したい施設があることを確認します。
3. 「新規予約」で施設を選び、開始日時と終了日時を入力します。
4. 必要なら「目的 (任意)」を入力します。
5. 「予約する」を押します。

予約を取り消すときは、「自分の予約」で対象を確認して「キャンセル」を押します。取り消した予約を画面から元に戻す操作はないため、日時と施設をよく確認してください。必要になった場合は新しく予約し直します。

<a id="confirm-success"></a>
## 成功を確かめる

予約後に画面が更新され、「自分の予約」に施設ID、開始日時、入力した目的が表示されれば完了です。キャンセル後は、その予約が一覧から消えたことを確認します。

<a id="troubleshooting"></a>
## 困ったとき

- 「開始 / 終了を入力してください。」と表示されたら、両方の日時を入力します。
- 「その時間帯は既に予約があります (重複)。」と表示されたら、別の時間帯または施設を選びます。
- 「予約に失敗しました」と表示されたら、「更新」を押して現在の予約を確認してから、もう一度操作します。
- 「予約一覧を取得できませんでした。」と表示された場合は、接続が戻ってから「更新」を押します。
