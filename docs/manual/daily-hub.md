<a id="capabilities"></a>
## できること

「🏠 ダッシュボード」で、その日の「5分クエスト」、自分のプロフィールと役職、直近30日の記録、最近のアクティビティをまとめて確認できます。進行中のプロジェクトが登録されている日は「今日のスポットライト」も表示されます。

<a id="before-starting"></a>
## 始める前に

ログインと初回登録を済ませてください。まだの場合は[初めてログインする](./first-use.md)を先に行います。

<a id="complete-daily-quest"></a>
## 操作する

1. 「🏠 ダッシュボード」タブを開きます。ログイン直後は通常、このタブが最初に開きます。
2. 「きょうの5分」に表示された「5分クエスト」の内容を読み、取り組みます。
3. 終わったら「できた！」を押します。
4. 「今日のスポットライト」に「プロジェクトを見る」がある場合は、選ぶとそのプロジェクトの公開ページを別のタブで開けます。
5. 「わたしの記録」と「最近のアクティビティ」で、出席、参加プロジェクト、技術リンク、フォーラム投稿などの記録を確認します。

<a id="confirm-success"></a>
## 成功を確かめる

ボタンが「達成済み ✓」に変わり、「今日の達成を記録しました。」と表示されれば、その日のクエストは記録されています。

<a id="troubleshooting"></a>
## 困ったとき

- 「日付が変わりました。画面を再読み込みしてください。」と表示されたら、再読み込みして新しい日のクエストを確認します。
- 「記録できませんでした。もう一度お試しください。」と表示されたら、接続を確認してもう一度「できた！」を押します。
- 「まだ記録がありません。」は、最近の対象活動がない状態です。出席や情報共有を行うと、その活動が表示されます。
- スポットライトに「制作仲間にスポットライトを当てよう」と表示される日は、紹介できる進行中プロジェクトがまだ登録されていません。
