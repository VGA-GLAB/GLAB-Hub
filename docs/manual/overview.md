<a id="capabilities"></a>
## できること

VANTAN GLab は、出席、施設予約、制作プロジェクト、相談や情報共有などを一か所に集め、部活動を支援する超パワーツールです。ログインすると、最初に自分の情報と今日の活動をまとめた「🏠 ダッシュボード」が開きます。

<a id="before-starting"></a>
## 始める前に

案内された Cernere アカウントを用意してください。初めて使うときは、名前・役職・学科の登録が必要です。本人確認が済んでいることと、GLAB の部員として扱われることは同じではありません。利用できる範囲が分からない場合は運営者に確認してください。

出席や施設予約では、会場のネットワークや連携サービスなど追加の準備が必要です。各章の「始める前に」を確認してから操作してください。

<a id="use-glab"></a>
## 操作する

1. VANTAN GLab を開いてログインします。
2. 初回登録が表示されたら、名前・役職・学科を登録します。
3. 画面のタブから目的の機能を開きます。

よく使う操作は次の章から始められます。

- [初めてログインする](./first-use.md)
- [ダッシュボードで今日の活動を始める](./daily-hub.md)
- [イベントに出席する](./attendance.md)
- [施設を予約する](./facility-reservation.md)

<a id="confirm-success"></a>
## 成功を確かめる

ログイン後に「🏠 ダッシュボード」が表示され、ヘッダーに自分の名前または利用者IDが表示されれば、GLABを開けています。目的のタブを選ぶと、その機能の画面へ切り替わります。

<a id="troubleshooting"></a>
## 困ったとき

- 「セッションが切れました。 再度ログインしてください。」と表示されたら、もう一度ログインします。
- 「起動に失敗しました」または「パネルの読み込みに失敗しました」と表示されたら、時間をおいて再読み込みします。続く場合は、その表示を運営者へ伝えてください。
- タブ内に「未接続」と表示された機能は、その機能の連携先が利用できるまで待ってください。ほかのタブは引き続き利用できます。

<a id="next-steps"></a>
## 次にできること
