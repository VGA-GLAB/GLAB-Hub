# フォーラムと役職

`glab_role_def` は役職名、`glab_member_role` は Cernere user id への役職付与だけを保持する。表示名は要求時に解決し、GLAB は氏名を複製しない。

フォーラムの `audience_roles` が空なら全員に可視である。値がある場合は役職の交差、投稿者本人、または admin のみが可視である。この判定は一覧、詳細、コメントの各 API でサーバ側に適用し、非可視の詳細・コメントは 404 を返して存在を秘匿する。

役職限定スレッドは Discord へ通知しない。全員向けスレッドのみ `notified_at` を成功後に記録して #forum へ一度だけ通知し、投稿時の Discord メンションはすべて無効化する。
