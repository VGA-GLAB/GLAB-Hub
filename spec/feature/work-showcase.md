# 卒業生・在校生の作品一覧

既存 project-showcase を拡張し、GLab の制作プロジェクトを作品として紹介する。
作品の名簿と制作メンバーは既存 glab_project / glab_project_member を正本とする。

- 管理者が紹介文、卒業年度（未指定は在校生作品）、一覧への掲載を設定する。
- 管理者が Windows exe を GLab 内の SQLite BLOB に保存する。作品カードに公開 GitHub URL やソース、zip、README への導線を出さない。
- 配布は認証済みダウンロード API のみ。外部 URL へのリダイレクトや静的配信を行わない。
- アップロードは 64 MiB 以下に制限し、拡張子と MZ/PE executable signature を検証する。サーバーでは実行しない。形式検証はウイルス検査ではない。
- exe のない作品は掲載不可。更新で exe がなくなった場合は一覧から除外する。
- 制作メンバー本人だけがプロフィール掲載を選択・解除できる。初期値は非掲載。
- 公開プロフィールは表示名と本人が掲載した作品のみ。氏名・学科・顔写真等の個人データは返さない。
- 制作メンバー解除後は作品とのリンクを即時に除外する。
- プロフィール画面から自作品を選択でき、作品カードから作者の作品一覧を開ける。

公開範囲は「GLab利用者限定」（neco回答）。一覧・ダウンロード・プロフィール作品一覧のすべてに利用者ログインを必須とし、service principal だけでは利用不可。
応答は private, no-store。管理者は登録と配布ファイルの更新を行い、学生は本人のプロフィール掲載のみを操作する。
受入: 卒業年度で作品を探せること、非 exe がレスポンスに含まれないこと、
他人の作品をプロフィールへ掲載できないこと、非掲載・メンバー解除が即時反映されること。
